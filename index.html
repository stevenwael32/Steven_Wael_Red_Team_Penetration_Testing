Caesar Cipher in Python

A simple Python program that encrypts, decrypts and brute-forces text with the Caesar cipher, built for a Network Security course. Encrypt moves every letter forward by a secret shift, the key. Decrypt moves it back with the same key. Brute force skips the key and tries every possible shift until one reads like real text, which shows why a cipher with so few keys is easy to break.
